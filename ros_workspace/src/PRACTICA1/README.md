# Práctica 1: organización

Esta carpeta contiene los dos paquetes ROS 2 necesarios para la práctica:

- `practica_1/`: nodo Python, dividido por tareas del enunciado.
- `practica_1_interfaces/`: definición del mensaje personalizado opcional.

La correspondencia entre tareas, los comandos de compilación y ejecución, y la
explicación de los datos están en [practica_1/README.md](practica_1/README.md).
Los paquetes se compilan desde la raíz de `ros_workspace`, no desde esta carpeta.
